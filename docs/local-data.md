# JobTrail 本地数据说明

JobTrail 现在采用纯本地保存，不再依赖 Supabase 或其它云数据库。

## 数据保存在哪里

- 主要数据保存在当前浏览器的 IndexedDB 本地数据库中。
- 每次保存时也会同步写一份到 localStorage，作为兼容和兜底。
- 数据只属于当前浏览器/当前浏览器用户配置。如果更换电脑、浏览器或清理浏览器数据，需要通过备份文件恢复。

## 推荐日常备份方式

1. 定期在看板页点击 `导出 Excel`，保存一份可阅读的表格。
2. 重要修改后点击 `备份 JSON`，保存一份最适合恢复的数据备份。

## 从现有 Excel 恢复

如果 Excel 是 JobTrail 导出的文件，并且包含：

- `投递记录`
- `进展时间线`

在看板页点击 `导入 Excel` 后，系统会识别为完整备份，并在确认后恢复到本地数据库。

如果 Excel 只是普通表格，系统会走追加导入，不会覆盖当前本地数据。
